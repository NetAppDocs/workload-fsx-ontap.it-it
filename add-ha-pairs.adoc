= Aggiungere coppie HA a un file system in NetApp Workload Factory
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
Aggiungere coppie ad alta disponibilità (HA) per scalare un file system Single-AZ di seconda generazione FSx for ONTAP in NetApp Workload Factory per aumentare prestazioni e capacità.  Questa espansione offre maggiore scalabilità delle prestazioni e flessibilità rispetto ai file system di prima generazione.

.A proposito di questa attività
Le nuove coppie HA utilizzano lo stesso SKU e la stessa capacità per ciascuna coppia HA.

L'aggiunta di coppie ha non è supportata per quanto segue:

* Implementazioni ha Multi-AZ o file system FSX per ONTAP di prima generazione
* file system FSx for ONTAP con più di cinque macchine virtuali di storage
* File system FSX per ONTAP con LUN iSCSI
* Configurazioni che hanno la capacità SSD massima o prossima alla massima oppure che hanno raggiunto i limiti di allocazione IO


Prendi in considerazione quanto segue per l'aggiunta di coppie ha:

* Rimozione della coppia HA: non puoi rimuovere le coppie HA dopo averle aggiunte al file system.
* Tempo di esecuzione e limitazioni: l'aggiunta di coppie HA potrebbe richiedere circa 30 minuti. Valuta di aggiungere le coppie HA durante una finestra di manutenzione o durante periodi di bassa attività. Inoltre, l'aggiunta di coppie HA limita altre operazioni, come l'aggiunta di altre coppie HA, il provisioning di IOPS, l'aumento della capacità SSD e l'aggiornamento della capacità di throughput.
* Allocazione I/O: l'allocazione I/O automatica dipende dalla capacità di storage totale. L'allocazione I/O configurata dall'utente viene moltiplicata per il numero di coppie HA aggiunte.
* Cache NVMe: quando aggiungi coppie HA, la cache NVMe è abilitata per impostazione predefinita. Ti consigliamo di disattivare la cache NVMe per carichi di lavoro intensi.
* Numero di coppie ha: Consigliamo di espandere il file system fino a un numero pari di coppie ha per una distribuzione di dati bilanciata nelle coppie ha.
* Creazione di LUN: la creazione di LUN è possibile su un file system Single-AZ di seconda generazione solo se non esistono già LUN sul file system quando aggiungi coppie HA. La creazione di LUN è supportata solo su un file system con sei coppie HA o meno.


.Prima di iniziare
Prima di aggiungere coppie ha a un file system, esegui le seguenti operazioni:

* Rimuovi tutte le LUN iSCSI per fare scale-out del file system.
* Assicurati che il file system non abbia più di cinque VM di storage.


.Fasi
. Accedere utilizzando uno dei link:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html["esperienze di console"^].
. Seleziona il menu image:workloads-menu-icon.png["L'icona del menu hamburger viene utilizzata per navigare tra carichi di lavoro quali storage, eda, ai, database, vmware e amministrazione."] e quindi seleziona *Archiviazione*.
. Dal menu Archiviazione, selezionare *FSx per ONTAP*.
. Da *FSx per ONTAP* in *Informazioni*, selezionare l'icona della matita accanto a *Coppie HA*.
. Nella finestra di dialogo *Aggiungi coppie ha*, selezionare il numero di coppie ha da aggiungere al file system.
. Selezionare *Aggiungi* per confermare l'aggiunta delle coppie ha.


.Risultato
Workload Factory avvia il processo per aggiungere la/le coppia/e HA al file system. Il file system non è disponibile per altre operazioni come la creazione di volumi finché le coppie HA non vengono aggiunte. Puoi monitorare l'avanzamento dell'operazione nella scheda *Tracker*.
