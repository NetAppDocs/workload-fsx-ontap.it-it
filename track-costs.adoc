= Monitora i costi delle risorse in NetApp Workload Factory
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
Utilizza NetApp Workload Factory per monitorare i costi e l'utilizzo del tuo file system FSx for ONTAP, in modo da poter gestire i budget e ottimizzare le risorse in modo efficace. Usiamo AWS Cost Explorer per fornire il costo complessivo con dati che richiedono autorizzazioni minime. Il costo per risorsa (file system o volume) si basa sui calcoli di Workload Factory, che forniscono informazioni esclusive non disponibili tramite AWS Cost Explorer.



[[about-this-task]]
== A proposito di questa attività

Workload Factory ottiene i dati relativi ai costi e all'utilizzo per le risorse del file system FSx for ONTAP da AWS Cost Explorer utilizzando le seguenti autorizzazioni: `ce:GetCostAndUsage` e `ce:GetTags`. Vengono monitorati i seguenti dettagli di costo: tipo di utilizzo, SKU di utilizzo, tipo di deployment, utilizzo e costo totale.

Nella dashboard Cost, due schede forniscono il costo totale e il costo per risorsa.

* Il costo complessivo si basa sui dati estratti direttamente dall'API AWS Cost Explorer.
* Costo per risorsa ti mostra le stime dei costi per file system o volumi.
+
Per le risorse uniche, Workload Factory calcola i costi combinando l'utilizzo effettivo del livello di prestazioni, una quota proporzionale dei costi del livello di prestazioni allocata allo spazio allocato ma non utilizzato, le allocazioni di prestazioni distribuite per capacità e l'utilizzo del pool di capacità. Workload Factory moltiplica ciascun componente per il suo prezzo unitario per quella dimensione e somma i risultati per determinare il costo totale per ciascuna risorsa.



Workload Factory mostra sempre i dati su base mensile.

Puoi filtrare i dati relativi a costi e utilizzo per account AWS, credenziali, una o più regioni e intervalli di tempo, così da comprendere il consumo del tuo file system FSx for ONTAP. Puoi anche filtrare per uno o più file system e uno o più volumi all'interno di un file system.

Le chiavi e i valori dei tag di allocazione dei costi AWS aggiungono un ulteriore livello di filtro per individuare costi specifici. Un tag è composto da una chiave e un valore. Per filtrare in base alle chiavi e ai valori dei tag, assegna tag ai tuoi FSx for ONTAP file system. link:https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/cost-alloc-tags.html["Scopri di più sui tag di allocazione dei costi di AWS."^]

Oltre ai dati sui costi nella dashboard Cost, il riepilogo esecutivo dei costi generato dall'IA mostra i costi del tuo file system FSx for ONTAP e i modelli di spesa della tua organizzazione. Puoi generare file CSV delle risorse del tuo file system FSx for ONTAP da condividere con il tuo team e le parti interessate.



[[track-costs]]
== Tieni traccia dei costi

I costi visualizzati nella console di Workload Factory nella dashboard dei costi si basano sui dati di AWS Cost Explorer, che sono aggiornati ogni 24 ore.

.Prima di iniziare
Verifica che tu soddisfi i seguenti requisiti:

* Devi link:https://docs.netapp.com/us-en/workload-setup-admin/add-credentials.html["concedere credenziali con la politica di autorizzazione _visualizzazione, pianificazione e analisi_"^] in Workload Factory per tenere traccia dei costi di FSx per ONTAP.
* Per filtrare in base ai tag di allocazione AWS, verifica che ai tuoi file system FSx for ONTAP siano stati assegnati dei tag.


.Fasi
. Accedere utilizzando uno dei link:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html["esperienze di console"^].
. Seleziona il menu image:workloads-menu-icon.png["L'icona del menu hamburger viene utilizzata per navigare tra carichi di lavoro quali storage, eda, ai, database, vmware e amministrazione."] e quindi seleziona *Archiviazione*.
. Dal menu Archiviazione, seleziona *Costo*.
. Dalla dashboard dei costi, filtra i dati relativi a costi e capacità delle tue risorse FSx for ONTAP fornendo le seguenti informazioni:
+
.. *Account AWS*: seleziona gli account per i quali desideri visualizzare i dati sui costi.
.. *Credenziali*: seleziona le credenziali con autorizzazioni di _visualizzazione, pianificazione e analisi_.
.. *Regioni*: seleziona le regioni AWS per cui desideri visualizzare i dati sui costi.
.. *Intervallo dati sui costi*: seleziona l'intervallo di tempo in cui visualizzare i dati sui costi.
.. *Chiave tag di allocazione*: (Facoltativo) Seleziona una chiave tag di allocazione e il relativo valore per generare un report dettagliato dei costi per tutti i file system FSx for ONTAP associati al tag AWS.
.. *Valori del tag di allocazione*: (Facoltativo) Seleziona il valore della chiave del tag di allocazione associato alla chiave del tag di allocazione per generare un report dettagliato dei costi per tutti i file system FSx for ONTAP associati al tag AWS.


. Visualizza i *Dettagli sui costi* per le tue risorse FSx per ONTAP .




[[generate-cost-reports-for-your-fsx-for-ontap-resources]]
== Genera report sui costi per le tue risorse FSx for ONTAP

Genera report sui costi per risorse specifiche del file system FSx for ONTAP da condividere con le parti interessate.

.Fasi
. Nella dashboard dei costi, seleziona *Genera report*.
. Nella schermata Report, fornisci le seguenti informazioni:
+
.. *File system*: Seleziona uno o più file system FSx for ONTAP da includere nel report.
.. *Volume*: (Facoltativo) Seleziona uno o più volumi da includere nel report.




.Risultato
Workload Factory genera un report CSV che puoi scaricare.
